# RWFit SR16 project rules

- This is a clean-room interoperability project for the SR16 Smart Ring.
- Do not copy proprietary RWFit code or assets.
- Do not invent or guess BLE command bytes.
- Preserve the Phase 3 goal: a diagnostic APK for physical SR16 testing.
- Keep Health Connect export disabled or clearly separated until hardware data decoding is validated.
- Prefer Kotlin and Jetpack Compose.
- Document protocol discoveries and update the SDD at phase boundaries.
- Never claim an APK is built unless a real APK artifact exists.
